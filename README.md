# 🕵️ SPY WORD（GRAVITY版）

2チームに分かれて、スパイマスターのヒントから仲間のカードを当てるワードゲーム（コードネーム風）。GRAVITY の AgentSDK（ルーム通信）で動く1ファイルのHTMLです。

- ホストの端末が状態を管理して全員に配信（ホストが抜けたら次の人が引き継ぎ）
- 途中参加・観戦・退出からの復帰（同じ席に戻れる）
- ヒント履歴・チャット・効果音
- GRAVITYの外（普通のブラウザ）で開くと1人練習モード

## ファイル
- `game.html` … ゲーム本体（そのままGRAVITYに貼り付けて使用）

Firebase版は [SPY-WORD](https://github.com/marumaru25/SPY-WORD)。
